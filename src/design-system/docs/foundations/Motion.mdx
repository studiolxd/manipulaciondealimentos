# Movimiento

## Para qué se anima

Las animaciones explican qué ocurre, no decoran: un fundido marca el cambio de escena, el enunciado que se encoge
enseña dónde volver a encontrarlo y la tarjeta que sale indica hacia qué lado se ha respondido.

## Duraciones

| Token | Duración | Uso |
| --- | --- | --- |
| `motion.duration.scene-fade` | 600 ms | Cada mitad del cambio de escena (fundido a negro y vuelta) |
| `motion.duration.morph` | 450 ms | Un elemento que se convierte en otro (enunciado ↔ icono del HUD) |
| `motion.duration.exit` | 350 ms | Un elemento que sale de la pantalla (tarjeta deslizada) |
| `motion.duration.title-hold` | 2500 ms | Tiempo que el título de actividad está a la vista antes de desvanecerse |
| `motion.duration.typewriter-char` | 28 ms | Cada letra del texto que se escribe |
| `motion.duration.typewriter-pause` | 450 ms | Pausa tras cada frase del texto que se escribe |

El código del juego lee estas duraciones de los mismos tokens (`tokens.ts`), así que la animación CSS y los
temporizadores nunca se desincronizan.

## Curvas

`standard` (entrada y salida suaves) para transiciones de estado, `enter` para lo que aparece y `exit` para lo que
desaparece.

## Botones que avanzan

**Regla:** todo botón que lleva a otra escena usa `advance` (en `Button`, `OptionButtons` o la acción de
`DialogueScene`) y entra deslizándose hacia arriba mientras aparece con un fundido (`--slxd-button-enter-*`).
Avanzar se ve igual en todo el juego. Se muestran cuando la escena ya se ve (`sceneReady`), para que la entrada no
quede tapada por el telón; en la portada, además, después del logo y del aviso de girar el dispositivo.

## Movimiento reducido

Con «reducir movimiento» activado en el sistema (`prefers-reduced-motion`):

- El texto aparece entero, sin escribirse.
- El enunciado no se encoge animado: cambia directamente.
- La tarjeta deslizada no sale volando: se responde al instante.
- Los iconos animados, como el de girar el dispositivo, se quedan quietos.
- Los botones que llevan a otra escena solo aparecen con un fundido, sin deslizarse.
- Los fundidos entre escenas se mantienen, porque son cambios de opacidad sin desplazamiento.
