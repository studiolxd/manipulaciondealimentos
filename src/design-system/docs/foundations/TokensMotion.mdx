# Movimiento

Duraciones y curvas de las animaciones. El juego lee las duraciones de estos tokens, así que CSS y temporizadores no se desincronizan. Con «reducir movimiento» activado, las animaciones se acortan o desaparecen.

Cada capa solo apunta a la anterior: los componentes usan tokens de componente o semánticos, nunca primitivos.
