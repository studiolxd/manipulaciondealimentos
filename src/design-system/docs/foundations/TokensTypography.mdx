# Tipografía

Familias, tamaños, pesos e interlineados. Los tamaños de texto tienen un mínimo en píxeles reales para que se lean en pantallas pequeñas.

Cada capa solo apunta a la anterior: los componentes usan tokens de componente o semánticos, nunca primitivos.
