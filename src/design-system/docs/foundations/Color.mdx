# Color

La interfaz usa colores que **no existen en el mundo del juego**: las escenas son cálidas (madera, piedra, luz
dorada) y la interfaz es tinta, crema y un menta frío. Así nunca se confunde con el fondo. Ver
[Línea gráfica](?path=/docs/fundamentos-línea-gráfica--docs).

Los componentes nunca eligen un color de la paleta, sino un **rol** (texto, superficie, acción, feedback…).

## Paleta

| Familia | Tonos | Para qué |
| --- | --- | --- |
| Tinta (petróleo) | `900` y transparencias 94 %, 72 % y 35 % | Contornos, narración, HUD de cristal y sombras |
| Crema | `50` | Paneles claros y texto sobre tinta |
| Arena | `50`, `300` | Papel de los carnés y bordes de la documentación |
| Menta claro | `300` | Botón principal, botones de icono y pantalla de girar el dispositivo |
| Menta | `600`, `800` | Elemento seleccionado e iconos de acento, legibles sobre crema |
| Verde | `700`, `800`, `900` | Acierto y botón SÍ |
| Rojo | `700`, `800`, `900` | Error y botón NO |
| Blanco, negro y transparente | — | Texto (negro), fondo del escenario y del telón, bordes invisibles |

## Roles

| Rol | Uso |
| --- | --- |
| `color.text.*` | Texto en negro, inverso (crema), sobre menta (negro), acento (menta oscuro), positivo y negativo |
| `color.surface.*` | Panel claro, papel, panel de tinta (narración), cristal (HUD), pantalla de sistema (menta), tinta de referencia y fondo del escenario |
| `color.border.*` | Contorno de tinta, sin borde, borde suave y elemento seleccionado |
| `color.action.primary.*` | Botón principal y botones de icono: menta con texto negro y sombra de tinta |
| `color.action.secondary.*` | Opciones que actúan al pulsarlas: blanco con texto negro y sombra de tinta |
| `color.action.positive.*` / `negative.*` | Botones SÍ y NO |
| `color.feedback.*` | Acierto (verde) y error (rojo) |
| `color.focus.*` | Anillo de foco doble: crema por dentro, tinta por fuera |

## Normas

- **El color nunca va solo.** Un acierto o un error se comunican también con icono, texto y banda lateral.
- **Contraste mínimo WCAG AA:** 4,5:1 para texto y 3:1 para controles y el foco.
- **Nunca hay texto directamente sobre la ilustración:** va en un panel o con el tratamiento de título (contorno y sombra).

## Contrastes

| Par | Contraste | Cumple |
| --- | --- | --- |
| Negro sobre crema (bocadillos, tarjetas) | 19,7:1 | AA y AAA |
| Crema sobre tinta (narración, HUD, títulos) | 14,8:1 | AA y AAA |
| Negro sobre papel (carnés) | 20,7:1 | AA y AAA |
| Negro sobre menta `#A6F0D3` (botón principal, pantalla de girar) | 16,0:1 | AA y AAA |
| Blanco sobre verde `#15803D` (botón SÍ) | 5,0:1 | AA |
| Blanco sobre rojo `#B91C1C` (botón NO) | 6,5:1 | AA |
| Verde y rojo sobre crema (texto de acierto y error) | 4,8:1 y 6,1:1 | AA |
