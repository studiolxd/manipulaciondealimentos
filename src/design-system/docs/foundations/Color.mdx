# Color

La paleta es **provisional**: se ajustará cuando llegue la línea gráfica del juego. Lo que no cambiará es cómo se
usa: los componentes nunca eligen un color de la paleta, sino un **rol** (texto, superficie, acción, feedback…).

## Paleta

| Familia | Tonos | Para qué |
| --- | --- | --- |
| Blanco y negro | `white`, `black` | Superficies, texto sobre color, fondo del escenario y del telón |
| Neutros | `900`, `950` | Texto principal y pantallas de sistema |
| Arena | `50`, `300` | Objetos impresos (carnés) y sus bordes |
| Naranja | `700`, `800` | Acción principal y su estado al pasar el ratón |
| Verde | `700`, `800` | Acción secundaria (botones de icono) y aciertos |
| Rojo | `700` | Errores |
| Azul | `700` | Anillo de foco del teclado |
| Transparencias | blanco 94 %, negro 25 %, transparente | Paneles sobre una escena, sombras, bordes invisibles |

## Roles

| Rol | Uso |
| --- | --- |
| `color.text.*` | Texto normal, inverso (sobre fondos oscuros), positivo y negativo |
| `color.surface.*` | Paneles opacos, translúcidos sobre la escena, papel, pantallas de sistema y fondo del escenario |
| `color.border.*` | Sin borde, borde suave y elemento seleccionado |
| `color.action.primary.*` | Botón principal (naranja) |
| `color.action.secondary.*` | Botones de icono (verde) |
| `color.feedback.*` | Acierto (verde) y error (rojo) |
| `color.focus.ring` | Anillo de foco (azul) |

## Normas

- **El color nunca va solo.** Un acierto o un error se comunican también con icono y texto («¡Correcto!»,
  «¡Incorrecto!»), para quien no distingue los colores.
- **Contraste mínimo WCAG AA:** 4,5:1 para texto y 3:1 para controles y el foco.
- **Fondos transparentes:** el texto va siempre sobre una superficie, nunca directamente sobre la ilustración.
